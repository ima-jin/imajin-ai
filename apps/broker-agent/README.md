# @imajin/broker-agent

Telegram broker agent — conversational surface for broker-mediated social coordination.

## What this is

Runs inside this monorepo today. Whether it's a kernel rail or a third-party app under the [registered-app contract](https://github.com/ima-jin/imajin-ai/issues/1981) hasn't been decided yet — #1981 calls this out explicitly as undecided. It also isn't in the production process list (`deploy/ecosystem.prod.config.js`) yet, so treat it as early-stage.

## Run it

```bash
pnpm --filter @imajin/broker-agent dev
```

See the [root README](../../README.md) for the kernel/app boundary.
